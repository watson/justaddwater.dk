ACD See systems tells me this error message when I follow a link to an invoice.

Very funny that there is an error message telling me "no error message found".

[![acdsystems-no-error-message-found-thumbnail.png](/wp-content/uploads/2007/03/acdsystems-no-error-message-found-thumbnail.png)](/wp-content/uploads/2007/03/acdsystems-no-error-message-found.png "acdsystems-no-error-message-found.png")

I purchased an upgrade ACDSee license almost 2 months ago, but this is what happens when I try to follow the link in the invoice.

One good thing, however. Very handy for the developers and tech support to have an error codes shown. In this way, error messages are more traceable if an error happens.

I'm considering using this on a current project I'm working on. But we will probably end up hiding the technical error codes initially (but possible to show on a click on "technical info" link).
