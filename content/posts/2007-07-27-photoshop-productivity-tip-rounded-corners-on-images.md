I had to ask my old colleague and friend [Michael Bernth](http://www.bernth.dk/ "Michael Bernth homepage") for help today for a Photoshop tip.

I wanted to round the corners of an image with the shape of a rounded rectangle.

Here is an easy way (I'm using Photoshop CS1):

1.  \
2.  Start with an image in a separate layer. Create a new set (folder), and put the image into it.\
    [![photoshop-mask-create-new-set.png](/wp-content/uploads/2007/07/photoshop-mask-create-new-set.png)](/wp-content/uploads/2007/07/photoshop-mask-create-new-set.png "photoshop-mask-create-new-set.png")
    \
3.  Create the shape that will form the borders of the image. I'm using the "rounded rectangles tool".\
    [![photoshop-mask-create-rounded-shape.png](/wp-content/uploads/2007/07/photoshop-mask-create-rounded-shape.png)\
    ](/wp-content/uploads/2007/07/photoshop-mask-create-rounded-shape.png "photoshop-mask-create-rounded-shape.png")
    \
4.  CTRL + click the layer to select layer transparency
    \
5.  Hide layer with shape, still preserving the selection
    \
6.  Select the folder by clicking once on the set in layer list\
    [![photoshop-mask-select-folder.png](/wp-content/uploads/2007/07/photoshop-mask-select-folder.png)](/wp-content/uploads/2007/07/photoshop-mask-select-folder.png "photoshop-mask-select-folder.png")
    \
7.  Choose "Layer" \> "Add layer mask" \> "Reveal selection"\
    [![photoshop-mask-add-layer-mask-reveal-selection.png](/wp-content/uploads/2007/07/photoshop-mask-add-layer-mask-reveal-selection.png)](/wp-content/uploads/2007/07/photoshop-mask-add-layer-mask-reveal-selection.png "photoshop-mask-add-layer-mask-reveal-selection.png")
    

Finished result:

[![photoshop-mask-finished-result-rounded-corners.png](/wp-content/uploads/2007/07/photoshop-mask-finished-result-rounded-corners.png)](/wp-content/uploads/2007/07/photoshop-mask-finished-result-rounded-corners.png "photoshop-mask-finished-result-rounded-corners.png")

And voila! Now you can drop any image into the folder. You can move it around, copy, etc.

Another nice trick is to unclick the binding between the mask and the image. That way, you can move the mask around on a big image, to find just the right crop. (I felt like the start of a James Bond movie moving the mask around... :)
