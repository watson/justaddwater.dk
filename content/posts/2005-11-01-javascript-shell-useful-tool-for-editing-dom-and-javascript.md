Jesse Ruderman has a tool for live-editing JavaScript and DOM on any webpage. I have found it very useful and indispensable for rapid JavaScript development, bug finding in unknown code.

Couple of days ago I asked Jesse to consider some [improvements, which he now incorporated](http://www.squarefree.com/2005/10/30/javascript-shell-14/).

I really recommend this tool, especially the ability to investigate advanced web2.0 user interfaces. A good example is to try it out on Google Maps. Just go to [maps.google com](http://maps.google.com), open the JavaScript Shell, and type:\
`props(_m)` and `props(_m.map)`

You'll find the [JavaScript Shell on Jesse's site](http://www.squarefree.com/shell/). Be sure to get the bookmarklet version (for Firefox). He also maintains a [changelog](http://www.squarefree.com/categories/javascript-shell/).
