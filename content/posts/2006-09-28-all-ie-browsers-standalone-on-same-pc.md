Yousif Al Saif of Tredosoft is probably best known for the [IE7 standalone](http://tredosoft.com/IE7_standalone) browser installer that can run isolated on a Windows machine without disturbing the version already installed. I wrote about this in "[IE7, web standards and css support](/2006/08/28/ie-7-web-standards-and-css-support/)".

Now he posted an article that makes it dead simple to run multiple Internet Explorers. It's a simple one-click installer that makes you choose any of the following versions of IE:

- IE 6
- IE 5.5
- IE 5.0
- IE4.01
- IE3

Here's a screenshot of the installer:\
![Screenshot of Multiple IE installer](http://tredosoft.com/files/multi-ie/setup1.png)

Standalone versions of Internet Explorers have been available for a long time. (i blogged about it before back in [January](/2006/01/25/multiple-versions-of-ie-in-one-windows-pc-prepare-for-ie7/ "Justaddwater.dk: Multiple versions of IE in one Windows PC - Prepare for IE7") and [February](/2006/02/03/ie7-beta-running-side-by-side-with-ie6/ "Justaddwater.dk: IE7 beta running side by side with IE6")). The new and best thing is that it's now dead simple and really really easy to use.

### IE7 standalone

Tredosoft also has an installer that installs the most recent version of IE 7 as a standalone program (without removing IE6). It actually works very well for me, and I love that I'm able to test websites with the upcoming IE7 browser (currently release candidate 1).
