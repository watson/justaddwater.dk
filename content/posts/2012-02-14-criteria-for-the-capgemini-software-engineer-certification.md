It turns out i could not find any public web description of the certification I took last autumn while working with Capgemini.

I ended up at Level 2, which will have to meet all criteria from level 1 + the additional criteria from level 2.

So for convenience i will post all details here.

The table below is extracted from my certification sheet:

(bwt, i also have put the table below as a [software engineer Certification Criteria](http://justaddwater.dk/wp-content/uploads/2012/02/software-engineer-Certification-Criteria.html))
