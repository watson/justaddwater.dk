Ben Goodger from the core Firefox development team has written about some usability issues that they've been working on: [Improving Tabbed Browsing](http://weblogs.mozillazine.org/ben/archives/009210.html).

One of the problems were that the "close tab" button was not discoverable (placed to the right of all tabs). I made this screenshot in case you don't use Firefox:

![Firefox tabs and close tab button - Firefox 1.0](http://static.flickr.com/33/62926405_edd5c4e356_o.png)

> The results showed that the set of people sampled were generally capable of recognizing the tab strip, and switching between documents. We found though that unpredictable behavior of the back button (new tab = blank session history) is still a problem, since users expect clicking back to go back. What we also found is that the users we sampled were by and large using the context menu to close tabs. Some tried to close the entire browser window first, and most paused before trying the context menu.

What I think is *really* interestning is that usability work is done. Usability work made Firefox easy to use. Usability testing ensures a simple user interface. Here's what changes they tested:\
![Firefox tabs and close tab button - Firefox 1.0](http://static.flickr.com/31/62926406_60583ee4e6_o.png)

Very clear and very well thought of. Now the tabs are connected with the function "close". And if the tabs are small, the close button is hidden on inactive tabs. The latter is similar to a user interface feature Netvibes.com: Close button appears on mouseover.

[![screenshot netvibes hover](http://static.flickr.com/28/62926403_8a703c719a.jpg)](http://www.flickr.com/photos/jesper/62926403/ "Netvibes.com user controls appear on mouseover. Click to enlarge")
