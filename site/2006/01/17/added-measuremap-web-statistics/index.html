Added MeasureMap web statistics

We just started using MeasureMap and have added it to this blog after Jared Spool recommended it in a comment.

Recently I have looked for better ways to display incoming links (referring URLs), Google Analytics can but it’s a tedious process. The WordPress Dashboard can only show some of the incoming links.

I must say that this part is done very well in MeasureMap.

MeasureMap list of incoming links

It really works well. It seems updated very frequently (maybe even real-time, which I haven’t tested).

Later on, we might publish a comparison of Google Analytics vs. MeasureMap.
