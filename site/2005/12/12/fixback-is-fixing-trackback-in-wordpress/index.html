FixBack is Fixing Trackback in WordPress

I’ve been a bit irritated with WordPress for a while now (our blogging software for justaddwarer.dk). For some reason most of our trackbacks from other blogs seem to use ugly styled permalinks. With that I mean http://justaddwater.dk/?p=41 instead of the much nicer http://justaddwater.dk/2005/12/12/fixback-is-fixing-trackback-in-wordpress/.

So I decided to do something about it and after 30 seconds of Googling I found that I was not alone with my irritation. Bennett from the blog “semicolon – Software, the Internet and you” is reporting in the post “WordPress pingback and trackback bug” that this is a known issue that occurs when the post-author first saves his post as a draft before publishing it.

But anyway, to the point: Bennett has also published a WordPress plugin that should fix this bug temporarily (along with a description of how the bug should be fixed more permanently). To download and install this plugin see “FixBack: a WordPress plugin”.

I write this post partly to inform you guys about the plugin (if you too are using WordPress) and also to of cause test it and see if the trackbacks will appear correctly now.
