Bad Usability Calendar 2007 in Danish

Thomas Baekdal and I have translated and are now publishing Bad Usability Calendar 2007 in Danish.

I can highly recommend using this calendar in projects as wallpaper. But good luck on using it for actual planning.

This year’s version contains advice regarding AJAX, overwhelming use of graphics, advertising, and much more.
