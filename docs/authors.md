# Authors and sidebars on the original

Researched from the live original (http://justaddwater.dk) and `mirror/justaddwater.dk/` (WP 5.1.27, Kubrick-based theme, plugin `JAWAuthorWidgets`).

## Sidebar per page type

| Page type | `#content` | Sidebar |
|---|---|---|
| Home, `/page/N/`, fixed pages (`/about-the-authors/`, `/privacy/`, `/contact-us/`, `/blogtools/`, ...), category, tag, `/YYYY/`, `/YYYY/MM/`, `/author/<slug>/` | narrowcolumn | 4 widgets: Search form; "Authors" text ("This blog is written by Jesper Rønn-Jensen from NineConsult and Thomas Watson Steen from 3dbyggeri danmark." + "About the authors" link); "Subscribe to this Blog" (by e-mail link + feed icon); "Pages" list (Contact us, Justaddwater.dk tools page, WordPress Plugins, Creating Passionate Users website printing problems solved in CSS, Jesper's Notes "Elements of User Experience") |
| Single post by jesper | widecolumn | only "About the Author": photo (`userphoto/2.jpg`, title/alt "Photograph of author Jesper Rønn-Jensen") + 2 paragraphs of bio |
| Single post by admin (= Thomas) | widecolumn | only "About the Author": photo `userphoto/1.jpg` (alt "Photograph of author Thomas Watson Steen") + 1 paragraph of bio |
| Single post by luis | widecolumn | empty sidebar (`<div id="sidebar"><ul></ul></div>`, no photo, no bio) |
| `/archive/` | widecolumn | no sidebar element at all |

There is no "About the Authors" block with all authors; the "Authors" text widget above is what non-post pages show. Mirror counts agree: 368 jesper posts and 71 admin posts (x2 URL forms) show the single-author box.

## Author mapping

| WP login (`dc:creator`) | slug (`author:`) | Display name | Photo | `/author/<slug>/` on original | Content |
|---|---|---|---|---|---|
| jesper | jesper | Jesper Rønn-Jensen | `static/images/jesper.jpg` (= `2.jpg`) | 200 | 368 posts, 6 pages |
| admin | thomas | Thomas Watson Steen | `static/images/thomas.jpg` (= `1.jpg`) | `/author/admin/` and `/author/thomas/` both 404 | 71 posts, 7 pages |
| luis | luis | Luis Villa | none | 200 (1 post) | 1 post (`/2006/06/25/ten-reaffirmations-from-london-media-2006/`) |

admin = Thomas is confirmed: the `wp:author` entry for login `admin` has display name "Thomas Watson Steen", and the original's sidebar on admin posts (e.g. `?p=435`) shows photo 1.jpg with Thomas's bio. Author data lives in `data/authors.yaml`; `bin/export-to-hugo` writes `author:` front matter (admin -> thomas).

## Author archives

`/author/<slug>/` heading is "Author Archive" (`<title>`: "justaddwater.dk | <display name>"); only authors with `archive: true` are generated by `content/archives/_content.gotmpl` (jesper, luis), listing that author's posts, 20 per page. Thomas/admin 404 on the original and here.
