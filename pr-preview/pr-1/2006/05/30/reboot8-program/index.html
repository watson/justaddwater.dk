Reboot8 Program Finally Ready

[updated with Friday program]

I’ve been very curious with respect to the conference program for reboot8 next week. Especially because I’ll be giving a short talk there.

I see from the Program page that now there is a program available for Thursday at least the entire conference. I just mailed Thomas Madsen-Mygdal to ask if the other half of the program is on the way. Also, it seems like Michael Heliemanns Google Calendar is not yet updated with the schedule (at least not in my Google Calendar).
I’ll be speaking in the “demos” section somewhere between 16.45 and 17.30.
