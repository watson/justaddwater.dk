# Original justaddwater.dk theme (`jaw`, Kubrick-based)

Copied from the wget mirror so it is versioned. Use it to match the old look.

- `style.css` — main theme stylesheet (fonts: Lucida Grande / Trebuchet MS / Verdana; colours and widths inside)
- `inline-head.css` — the inline `<style>` blocks from the original page `<head>` (page background, contact form)
- `images/` — header, page and footer backgrounds referenced by both CSS files
- `block-library.min.css` — WordPress core block styles (usually not needed)
